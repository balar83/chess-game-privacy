# Chess Game — Privacy Policy

Single-page privacy policy for the Chess Game Android app (`com.chessgame.app`), hosted via GitHub Pages for use as the Google Play Console privacy policy URL.

This repository intentionally contains nothing else — no app source, no build artifacts, no other product content.

## Publishing

1. Push this repository to GitHub as a **public** repo.
2. In the repo's Settings → Pages, set source to "Deploy from a branch", branch `main`, folder `/ (root)`.
3. GitHub Pages will serve `index.html` at the resulting `github.io` URL.
